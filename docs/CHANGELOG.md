# 更新紀錄

格式參考 Keep a Changelog，版本遵循語意化版本。每項標 PRD 的 User Story（US）編號。

## [1.1.0] - 2026-11-11

對應 PRD v1.4。第一個公開版本（Apache-2.0）；1.0.0 打包完成但沒有對外發佈，這一版一併修正它之後發現的問題。

### 安全

- 自動填入：瀏覽器與一般 App 都要比對簽署憑證，冒用套件名稱的 App 不能自稱網域；一般 App 第一次使用時記下憑證，換了就不自動交出（US-10）
- 自動填入：https 的條目不建議給 http 的頁面；上層網域比對採用公開後綴清單（例：`github.io`、`co.uk` 不算共同上層）；也比對 `KP2A_URL` 附加網址（US-10）
- 自動填入：建議清單不再帶帳密的值，每次點選都先確認 S-Vault 仍解鎖、條目仍符合；已上鎖時先開解鎖畫面（避免上鎖後點舊建議仍能填入）（US-10）
- 存檔：寫入遠端前再讀一次，合併之後剛好被別的裝置寫入時不覆蓋、重新合併；讀回驗證比對附件與歷史紀錄的內容（US-09）
- 合併：整份取代時參考 KeePass 的刪除紀錄，另一台離線期間永久刪除的條目不再復活（有通知）（US-07）
- 金鑰衍生：成本遠高於一般設定的檔案先確認再開；設定偏弱的檔案提示並可一鍵升級（US-01）
- Windows：解鎖時預設阻擋螢幕截圖與畫面分享（設定可關）；本機資料夾的權限收緊成只有自己與 SYSTEM（US-12）
- 匯入的 CSV 限制欄位數與筆數；本機讀檔有大小上限；外洩檢查有整體時限（US-13、US-14）
- 相依套件以 SHA-256 校驗（含三個平台的 aapt2）

### 修正

- 匯入、產生器等頁面回到條目畫面時群組樹被擠到最小寬度；長的群組名稱滑鼠停留時顯示完整名稱（US-02）
- Android 最大字體加上鍵盤時，「已上鎖」「已複製」提示蓋住按鈕（US-02、US-04）
- Android：Google 雲端硬碟垃圾桶裡的保管庫顯示「找不到」，不再誤報成離線，也不會寫進垃圾桶（US-06）
- 開 S-Vault 自己的檔案選擇器時，「立即上鎖」不會讓選檔作廢（最多寬限 2 分鐘）（US-12）
- 建立保管庫時名稱結尾已經是 `.kdbx` 不會變成 `.kdbx.kdbx`；剪貼簿清除暫時失敗時有限次重試（US-01、US-05）
- 不分隔的通行片語每個單字開頭大寫，避免單字黏在一起時降低強度（US-04）

### 變更

- Android 第一次解鎖後自動顯示自動填入的設定引導（US-10）
- Windows 打包版改用精簡的執行環境（152.8 → 135.2 MB）
- 產生器、健檢、匯入的畫面邏輯兩平台共用同一份

### 已知限制

- 不支援金鑰衍生為 Argon2id 的檔案（請在 KeePassXC 改成 Argon2d）；不支援 KDBX 3.1、Twofish
- 自動填入：已經填進對方 App 的內容、以及驗證後交給系統的那一筆，上鎖後無法收回
- Windows 安裝檔沒有程式碼簽章，安裝時 SmartScreen 會警告；Android 不上架，需允許安裝不明應用程式

## [1.0.0] - 2026-11-04（未對外發佈）

對應 PRD v1.4。第一個正式版本：Windows（JavaFX）與 Android 共用同一個 Google Drive 上的 KDBX 4 保管庫。

### 新增

- 用主密碼建立與解鎖保管庫；檔案是標準 KDBX 4（Argon2d 64 MiB／2 次／平行度 4、AES-256），KeePassXC 開得了、S-Vault 沒用到的欄位與附件原樣保留（US-01）
- 條目與群組的新增、編輯、刪除，資源回收桶（US-02）
- 搜尋名稱、帳號與網址（US-03）
- 密碼產生器：隨機密碼與 EFF 字表的通行片語，條目編輯畫面可直接產生（US-04）
- 複製帳號或密碼，剪貼簿依設定秒數自動清除；Windows 不進剪貼簿歷程與雲端剪貼簿，Android 標為敏感內容（US-05）
- PC 從 Drive 電腦版資料夾、Android 從系統檔案選擇器開啟同一個保管庫（US-06）
- 偵測另一台裝置的修改，以本機的上次同步版本為基準三方合併；遠端被整份取代時兩邊的條目都保留（US-07）
- 同一筆條目同一欄位兩邊不同時，逐欄對照讓使用者選（US-08）
- 每次存檔前自動備份 10 份；PC 原子取代、Android 覆寫後讀回比對；從備份還原（US-09）
- Android 自動填入：依套件名稱或瀏覽器網域比對、上鎖時先解鎖、不符時警告（US-10）
- Android 生物辨識解鎖（Keystore 保護的金鑰，按錯次數上限）（US-11）
- 閒置與螢幕關閉自動上鎖、Windows 鎖定時上鎖、Android 防截圖（US-12）
- 密碼健檢：弱密碼、重複使用、外洩檢查（只在使用者按下並確認後連線，只送 SHA-1 前 5 碼）（US-13）
- 從 Chrome 匯出的 CSV 匯入，預覽重複與格式錯誤的列，完成後提示刪除 CSV（US-14）
- 威脅模型與防護，以及相容性、加密規則、日誌不含機密、合併的自動化測試（US-15）
- 功能模組（產生器、健檢、匯入、生物辨識、自動填入）可以各自停用

### 安全（發佈前資安總檢，2026-11-03～11-04）

- 自動填入的網域只採信已知瀏覽器，其他 App 自稱的網域不算數（US-10）
- 自動填入不把帳密填進跨網域 iframe 的欄位（US-10）
- 金鑰衍生參數過大（記憶體 > 256 MiB 等）或檔案超過 256 MiB 時不開啟，避免被竄改的檔案讓解鎖卡死（US-01）
- 外洩檢查的位址只接受 https（本機測試伺服器除外），回應單列長度有上限（US-13）
- Android release 開啟 R8；Gradle 發佈檔有校驗碼、CI 的 Actions 以 commit SHA 固定、打包出去的相依版本有鎖定檔

### 已知限制

- 不支援金鑰衍生為 Argon2id 的檔案（上游 KeePassJava2 2.2.7 發佈後開放，T-26）；不支援 KDBX 3.1、Twofish
- Windows 安裝檔與 Android APK 都沒有經過商店或程式碼簽章服務；Windows 安裝時 SmartScreen 會警告
- 其他較小的已知問題沒有逐一列出
